My Half week 1 PCB Project
What is this?
This is my PCB project for Hack Club’s Half Life. I’m making an ESP32-based project and designing a custom PCB for it.

I wanted to use this project to get more comfortable with PCB design, electronics, and coding.

What I’ve Done
So far, I’ve:

Designed the PCB in KiCad
Made a custom bat-shaped board outline
Learned how Edge.Cuts works
Started setting up the ESP32
Set up ESP32 boards in Arduino IDE
Started working on the code
Tested and verified parts of the code without the physical board
My Process
I started by making the basic shape of the PCB and adjusting it until I was happy with it. I decided to make it a bat shape instead of just using a basic rectangle.

After that, I started working on the electronics and ESP32 setup. I’ve also been learning how the Arduino code connects to what I want the actual project to do.

Since I don’t have the physical PCB yet, I’ve mainly been working on the design and code that I can test without the hardware.

What I Learned
I’ve learned a lot about KiCad and PCB design while working on this. I also got more familiar with ESP32 boards and how to set them up in Arduino IDE.

One thing I’ve learned is that things don’t always work the first time, so I’ve had to change things and figure out what was causing problems along the way.

Current Progress
The PCB design is still being worked on, and I’m continuing to work on the Arduino code, I got really busy with making different images so my "pet" changes depending on what it does to make the project a bit more fun and interactive.

My next step is to finish up the design and eventually test everything with the actual hardware.

What I Want to Add Later
Finish the PCB
Test it with the actual ESP32
Test the code on the hardware
Fix anything that doesn’t work
Add more features if I have time
